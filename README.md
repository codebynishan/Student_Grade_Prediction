## Student Performance Prediction

* Project Overview
This project predicts the final grade (G3) of students based on various factors such as study time, family background, health, and past academic performance. The dataset used is from Kaggle.
Machine learning is used to build a predictive model that helps understand which factors influence student performance the most.

* Objective
- Predict the final grade (G3) of students
- Understand key factors affecting student performance
- Evaluate model performance using Mean Squared Error (MSE) and R² Score

* Tools & Libraries Used
- Python 
- Jupyter Notebook
- Pandas,Numpy,Seaborn,Matplotlib
- Scikit-learn

* Conclusion
- Linear Regression performs well for predicting final grades
- Past grades (G1, G2) are the most important predictors
- Model can be used for educational insights and planning interventions
